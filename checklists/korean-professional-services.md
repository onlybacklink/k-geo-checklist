# 한국 전문직·로컬 비즈니스 K-GEO 체크리스트

> 대상: 의료·법률·세무/회계·교육·부동산·건축/인테리어·미용/웰니스 등 한국 전문직·로컬 비즈니스.
> 원칙: 글로벌 4엔진(ChatGPT·Perplexity·Gemini·Grok)은 실측, 네이버 AI 브리핑은 별도 관측. 과장·보장·1위 표현 금지.

## A. 기술 토대 (AI가 읽게)
- [ ] robots.txt에서 AI 크롤러 미차단 (GPTBot, PerplexityBot, Google-Extended, ClaudeBot 등)
- [ ] Organization / LocalBusiness JSON-LD (상호·주소·전화·영업시간·지역)
- [ ] FAQPage JSON-LD (실제 고객 질문 4~6쌍)
- [ ] sitemap.xml 제출 + canonical 정리
- [ ] 모바일·속도·서버 렌더링 핵심 콘텐츠

## B. 콘텐츠 (AI가 발췌하게)
- [ ] 각 페이지 첫 문단 = 의미 삼각형(주어-동사-목적어) 40~60단어 직답
- [ ] 질문형 제목/소제목(고객이 AI에 실제로 묻는 말)
- [ ] 비교·단계·가격은 표/번호 목록
- [ ] 정확한 수치 + 출처(추정·과장 금지)

## C. 외부 인용 (AI가 신뢰하게)
- [ ] 같은 회사 정의가 LinkedIn·Wikidata·디렉터리·네이버 블로그·언론에 일관
- [ ] NAP(상호·주소·전화) 모든 채널 동일
- [ ] 업종 디렉터리/커뮤니티에 가치형 정보(홍보·복붙·가짜후기 금지)

## D. 한국형(네이버 AI) 보강
- [ ] 네이버 블로그: 질문형+직답 정보 글(주 1~2회 일관)
- [ ] 네이버 지식iN: 실제 질문에 체크리스트형 답변(첫 2문장 변형)
- [ ] 네이버 플레이스: 지역·업종 기본정보 정확

## E. 업종 광고 규제 (필수)
- [ ] 의료: 환자 후기·기관 비교·효과 보장·"최고/1위" 금지 (의료법 제56조) → 정보 글로서리+FAQ
- [ ] 법률: 능력·승소율 과대 금지 (변호사법 제23조) → 사건 유형별 절차 안내
- [ ] 부동산: 허위·과장 표시·광고 금지 (공인중개사법) → 시세 근거·리스크 함께
- [ ] 미용: 비의료 미용/운동과 의료행위(피부 시술 등) 구분, 효과 단정·전후 과장 금지

## F. 측정·반복
- [ ] 글로벌 4엔진 노출 점수 + 네이버 AI 브리핑 관측 분리 기록
- [ ] 약한 질문/엔진부터 콘텐츠 보강 → 재측정 (월 1회)
